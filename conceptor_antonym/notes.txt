To extract the hidden vector for a given task, we use in context examples like:
here:Here,joy:Joy,happy:
To see that entire contribution is done by steering and no contribution by model's internal knowledge,
we only give input as a single token and then check the output token generated by LLM.

Why it's built this way
The steering intervention has to substitute for the demonstrations. The model gets no clue what task it's doing — without: alone is meaningless — so any accuracy above zero is attributable entirely to the injected C or v carrying the task.

Your baseline CSV confirms the design works as intended: 0/3000, exactly 0.0% unsteered. And since steered runs reach ~0.49, the token comparison is functioning (a broken BPE-marker comparison would have pinned everything at zero).
